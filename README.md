- **Weld analysis:** Built an end-to-end Python and computer vision pipeline for melt-pool, pore, and crack segmentation, measurement, annotation, and reporting.
- **Electric vehicle systems:** Worked on VCU software, CAN data integration, LoRa telemetry, and Nextion HMI visualization for the ITU KASVA electric car team.
- **Manufacturing improvement:** Conducted time studies, improved workstation layouts, and built an offline production time-tracking tool during a Baymak internship.
